# TU BSc Agriculture Entrance Interactive Course

Interactive HTML course for TU/IAAS BSc Agriculture entrance practice.

## Files

- `index.html` - interactive course app
- `tu_bsc_ag_entrance_200_practice.md` - 200-question practice source

## GitHub Pages

After pushing this folder to GitHub:

1. Open the repository on GitHub.
2. Go to Settings > Pages.
3. Under "Build and deployment", choose "Deploy from a branch".
4. Select the `main` branch and `/root`.
5. Save.

Your course will open at:

`https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/`

Keep the Markdown file beside `index.html`; the course loads questions from it.
